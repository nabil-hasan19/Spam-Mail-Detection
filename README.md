# Spam Mail Classification Using Machine Learning

## 📌 Project Overview
This project focuses on classifying emails as Spam or Ham (legitimate emails) using machine learning techniques. It demonstrates how machine learning can be applied to identify unwanted emails and support email filtering systems.

## 🎯 Objectives
- Classify emails as spam or legitimate.
- Preprocess email text for machine learning.
- Train and evaluate a spam classification model.
- Explore machine learning applications in email filtering.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Machine Learning
- Natural Language Processing (NLP)

Open `spam_mail_project.ipynb` and execute the cells sequentially.

## 📊 Project Workflow
1. Load the email dataset.
2. Explore and preprocess the data.
3. Convert email text into numerical features.
4. Train a machine learning classification model.
5. Evaluate the model's performance.
